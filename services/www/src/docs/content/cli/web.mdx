---
title: "Web"
description: "Run HarishCode in the browser."
---

HarishCode ships with a web UI that is served from the same server that powers the
TUI. It's available by default and password protected.

## Access

```bash
$ harishcode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...

  █▀▀▀▀▀█ ...
```

Opening a link in a browser signs it in with a session cookie and loads the web
UI. Scanning the QR code from the HarishCode app, or pasting the link into its
server address field, connects the app the same way. Sessions last 30 days;
changing the server password signs every session out.

### Over SSH

When the server listens only on localhost, forward its port from your machine
and open the printed link locally:

```bash
$ ssh -L 49374:127.0.0.1:49374 my-server
```

By default the server listens only on localhost. Its port depends on the
platform:

| Platform              | Default port |
| --------------------- | ------------ |
| macOS, Linux, and WSL | 49374        |
| Windows               | 28894        |

Windows reserves ports from 49152 up, and WSL mirrored networking reserves
another block below that. Print the current address with
`harishcode service status`:

```bash
$ harishcode service status
http://127.0.0.1:49374
```

You can change this config with the `harishcode service` command.

### Remote access

To connect from anywhere, pair through an [OpenTunnel](https://github.com/harishpixous-commits/opentunnel)
remote address:

```bash
$ harishcode pair --remote
```

The first time it turns remote access on, it asks before going ahead:

```text
▲  This will expose your HarishCode server to the internet.
│  Traffic is end-to-end encrypted, and access requires your server password.
│  To pair locally instead, run `harishcode pair` without the --remote flag.
│
◆  Expose your server to the internet?
│  ● Yes / ○ No
```

Without an interactive terminal, the command fails unless you pass `--yes` to
accept. Once accepted, later runs skip the prompt, even after remote access has
been turned off with `harishcode service set remote false`.

## Configure

Set any option with `harishcode service set`:

```bash
# Listen on every network interface
$ harishcode service set hostname 0.0.0.0

# Use a fixed port instead of the channel default
$ harishcode service set port 49374

# Replace the generated password
$ harishcode service set password "a-long-secret"

# Allow a web client served from another origin
$ harishcode service set cors https://app.example.com,https://other.example.com

# Pass an environment variable to the server process
$ harishcode service set env HARISHCODE_LOG_LEVEL DEBUG
```

Changing a setting stops the background server. Start it again to apply the new config:

```bash
$ harishcode service start
```

## Standalone

`harishcode serve` runs the same server in the foreground instead of through the
shared background service.

```bash
$ harishcode serve --hostname 0.0.0.0 --port 4096
server listening on http://0.0.0.0:4096
server password <password>
```

Use it when you want to:

- Run HarishCode on a shared, always-on, or remote host, then connect clients with
  `harishcode --server <url>`.
- Control the hostname, port, and CORS origins for a single process.
- Run under a supervisor like systemd, Docker, or another environment that expects
  a foreground process.
- Keep a dedicated server instead of the shared background service.

Connect a client to it with `--server`:

```bash
$ harishcode --server http://127.0.0.1:4096
```

### Authentication

Set `HARISHCODE_PASSWORD` to use a fixed password instead of a generated one. The
same variable gives the password to `harishcode --server`.

```bash
$ HARISHCODE_PASSWORD="a-long-secret" harishcode serve --port 4096
$ HARISHCODE_PASSWORD="a-long-secret" harishcode --server http://127.0.0.1:4096
```

Other HTTP clients use Basic auth. The username is always `harishcode`, and only
the password can be changed.

```bash
$ curl -u harishcode:a-long-secret http://127.0.0.1:4096/api/info
```
