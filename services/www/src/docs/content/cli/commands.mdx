---
title: "Commands"
description: "Reference for the harishcode command line."
---

Every command accepts `--help` for its full flag list, for example `harishcode run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ harishcode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: HarishCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @harishcode/cli
      - run: harishcode run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ harishcode run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ harishcode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ harishcode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ harishcode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ harishcode run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ harishcode run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ harishcode run --auto "Fix the failing test"
```

View all subcommands and flags.

```bash
$ harishcode run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ harishcode mini
```

Continue the last session.

```bash
$ harishcode mini --continue
```

Start with a model and an initial prompt.

```bash
$ harishcode mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ harishcode mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ harishcode mini --help
```

## session

Manages sessions.

```bash
$ harishcode session list
```

Limit the list and print JSON.

```bash
$ harishcode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ harishcode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ harishcode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ harishcode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ harishcode session import session.json
```

Import into a specific directory.

```bash
$ harishcode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ harishcode session --help
```

## auth

Manages AI providers and credentials.

```bash
$ harishcode auth list
```

List them as JSON.

```bash
$ harishcode auth list --format json
```

Log in to a provider.

```bash
$ harishcode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ harishcode auth login anthropic --method key
```

Log out of a saved account.

```bash
$ harishcode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ harishcode auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ harishcode auth export anthropic > credentials.json
$ harishcode auth import credentials.json
```

View all subcommands and flags.

```bash
$ harishcode auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ harishcode mcp list
```

Add a remote server.

```bash
$ harishcode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ harishcode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ harishcode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ harishcode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ harishcode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ harishcode mcp logout sentry
```

View all subcommands and flags.

```bash
$ harishcode mcp --help
```

## plugin

Manages plugins.

```bash
$ harishcode plugin list
```

Include built-in server plugins.

```bash
$ harishcode plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ harishcode plugin add @example/harishcode-tui
```

Check package plugins for updates.

```bash
$ harishcode plugin check
```

Update package plugins.

```bash
$ harishcode plugin update
```

Remove a plugin from global configuration.

```bash
$ harishcode plugin remove @example/harishcode-tui
```

View all subcommands and flags.

```bash
$ harishcode plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ harishcode serve
```

Bind to all interfaces on a fixed port.

```bash
$ harishcode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ harishcode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ harishcode serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ harishcode pair
```

Use an external URL in the links.

```bash
$ harishcode pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ harishcode pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ harishcode pair --remote --yes
```

View all subcommands and flags.

```bash
$ harishcode pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ harishcode service start
```

Restart it.

```bash
$ harishcode service restart
```

Show its status.

```bash
$ harishcode service status
```

Stop it.

```bash
$ harishcode service stop
```

Read a setting.

```bash
$ harishcode service get hostname
```

Set a setting.

```bash
$ harishcode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ harishcode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ harishcode service set env HARISHCODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ harishcode service unset hostname
```

View all subcommands and flags.

```bash
$ harishcode service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ harishcode reload
```

## api

Makes a request to the running server.

```bash
$ harishcode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ harishcode api session.list --param limit=10
```

Send a JSON body.

```bash
$ harishcode api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ harishcode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ harishcode api --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ harishcode debug agents
```

List configuration sources.

```bash
$ harishcode debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ harishcode debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ harishcode debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ harishcode debug paths
```

Print a single path.

```bash
$ harishcode debug paths db
```

View all subcommands and flags.

```bash
$ harishcode debug --help
```

## upgrade

Upgrades HarishCode to the latest or a specific version. Alias: `update`.

```bash
$ harishcode upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ harishcode upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ harishcode upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls HarishCode. Session data, configuration, and
state are not removed.

```bash
$ harishcode uninstall
```

Preview what would be removed.

```bash
$ harishcode uninstall --dry-run
```

View all subcommands and flags.

```bash
$ harishcode uninstall --help
```
