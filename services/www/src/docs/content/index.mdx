HarishCode is an open source AI coding agent. It’s available as a terminal-based interface, desktop app, or web app.

The npm package uses a postinstall script to select the native `harishcode` binary for your platform. The Bun and pnpm commands
explicitly allow the required script; Vite+ requires no additional flag. The mise command requires mise 2026.10.9 or later;
older versions install HarishCode 1.

Windows package managers are not supported.


Download a standalone CLI binary for your platform.

- **macOS:** [Apple silicon](https://harishcode.ai/update/api/latest/cli/harishcode/harishcode-darwin-arm64.zip) · [Intel](https://harishcode.ai/update/api/latest/cli/harishcode/harishcode-darwin-x64.zip) · [Intel (baseline)](https://harishcode.ai/update/api/latest/cli/harishcode/harishcode-darwin-x64-baseline.zip)

## Web

Access the HarishCode web interface with the `harishcode pair` command.

```bash
$ harishcode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...
```

## Docker

Docker images use versioned tags, for example `ghcr.io/harishpixous-commits/Harishcode:2.0.0`.

## Connect

HarishCode has built-in support for many LLM providers. You can connect to them
directly [in the TUI](/cli/providers) with `/connect`.

See [Providers](/providers) to configure custom providers.

If you'd like easy access to all the best coding models you can try out
[HarishCode Console](/console).

You can also try [HarishCode Go](/console/go), a $10/month subscription
plan that grants you access to the best coding models.

## Customize

Make HarishCode your own by editing the [HarishCode config](/config), [loading plugins](/plugins), [connecting MCP
servers](/mcp-servers), or [creating commands](/commands). For terminal interface themes and keybindings, see [CLI
settings](/cli/config).
