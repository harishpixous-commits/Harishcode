ชุดโครงการชุมชนที่สร้างขึ้นบน HarishCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ HarishCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-harishcode](https://github.com/awesome-harishcode/awesome-harishcode) และ [harishcode.cafe](https://harishcode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
